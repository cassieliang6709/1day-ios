# 1Day 有题目模板文案工作稿

> 这是一份供中文精修的工作稿，不是最终文案。英文名、稳定 key 和当前实现先保留，优先修改「建议中文」与「建议说明」。

## 先统一几个原则

1. **模板名说“这是什么”，说明说“为什么值得拍”。** 不要两句都在描述功能。
2. **提示尽量是可遇见的画面，不是假设用户一定完成的任务。** 比如用“今天喝的”替代“喝咖啡”，用“一个小进展”替代“小胜利”。
3. **少用评价用户的词。** “完美”“主角”“自律”“不找借口”会让普通的一天显得不够资格被记录。
4. **提示是邀请，不是待办。** 用户应该可以跳过、更换，也不需要在创建故事时提前知道今天会发生什么。
5. **中文尽量像人会说的话。** 避免翻译腔和口号感；一个提示最好控制在 2–7 个字。

## 一天模板

### 1. Perfect Day

- 当前中文名：完美的一天
- 建议中文名：**今天刚刚好**
- 备选：值得重来的一天 / 喜欢今天
- 当前说明：愿意再过一遍的一天。
- 建议说明：**把今天喜欢的部分留久一点。**

| 顺序 | 当前提示 | 建议提示 |
| --- | --- | --- |
| 1 | 起床 | 醒来的第一眼 |
| 2 | 咖啡 | 今天喝的 |
| 3 | 收拾出门 | 出门前 |
| 4 | 出门 | 推门出去 |
| 5 | 正午 | 中午这一刻 |
| 6 | 傍晚的光 | 天快黑了 |
| 7 | 睡前放松 | 今天的最后一幕 |

建议：如果保留“完美”，用户会下意识判断今天够不够完美。“刚刚好”更松弛，也更像 1Day。

### 2. Soft Reset

- 当前中文名：慢慢重启
- 建议中文名：**慢慢恢复**
- 备选：重新顺起来 / 给自己缓一缓
- 当前说明：安静地重新开始。
- 建议说明：**不用一下变好，先让今天顺一点。**

| 顺序 | 当前提示 | 建议提示 |
| --- | --- | --- |
| 1 | 一团糟的开始 | 现在的样子 |
| 2 | 先清一样东西 | 先弄好一点点 |
| 3 | 整理一角 | 变整齐的一角 |
| 4 | 出去走走 | 到外面透口气 |
| 5 | 小奖励 | 给自己的小东西 |
| 6 | 温柔的细节 | 舒服一点了 |
| 7 | 之后 | 后来的样子 |

建议：“一团糟”太替用户判断；“现在的样子”更中性，也更容易拍。

### 3. Lock In

- 当前中文名：进入状态
- 建议中文名：**专注这一天**
- 备选：认真做一件事 / 今天先做完它
- 当前说明：先专注，其他都等等。
- 建议说明：**记录一件事从开始到完成。**

| 顺序 | 当前提示 | 建议提示 |
| --- | --- | --- |
| 1 | 布置桌面 | 开始前的桌面 |
| 2 | 第一段冲刺 | 正在开始 |
| 3 | 卡住了 | 不太顺的时候 |
| 4 | 补充能量 | 休息一下 |
| 5 | 突破 | 有一点进展 |
| 6 | 就快好了 | 快完成了 |
| 7 | 合上电脑 | 今天先到这里 |

建议：保留过程里的“不顺”，但不要用“冲刺、突破”把每次专注都写成竞技。

### 4. Main Character

- 当前中文名：我的主角日
- 当前说明：今天，镜头跟着你走。
- 首选建议中文名：**普通的一天**
- 备选：今天的我 / 我的一天 / 日常切片
- 建议说明：**从早到晚，留住今天经过的地方。**

| 顺序 | 当前提示 | 建议提示 |
| --- | --- | --- |
| 1 | 晨光 | 醒来时 |
| 2 | 今日穿搭 | 今天穿什么 |
| 3 | 在路上 | 去哪里 |
| 4 | 吃了什么 | 今天这一餐 |
| 5 | 小胜利 | 一个小进展 |
| 6 | 镜子前 | 今天的自己 |
| 7 | 夜晚 | 夜晚这一刻 |

建议：“主角”与“镜头跟着你”都很像短视频平台话术，也会给普通用户表演压力。这个模板的真实价值其实是：**即使没有特别的事，普通一天也值得留下。**

## 自定义提示页建议

当前流程最大的问题不是“七个问题写得不好”，而是它在创建时就要求用户预测今天。建议改成：

- 标题：**自定义提示**
- 说明：**写下你可能想拍的画面。先写 2 个也可以，之后随时能加。**
- 默认状态：2 个空白输入框，不自动填入建议答案。
- 每个输入框占位：**例如：出门前 / 今天这一餐 / 回家以后**
- 辅助入口：**从提示库里选**
- 完成按钮：**用这些提示**
- 规则：2–7 个均可；拍摄时允许“跳过”或“换一个提示”。

## 拍摄页文案建议

- 未拍摄：**轻点开始拍摄**
- 正在拍摄：**拍摄中 · 2 秒**
- 提前结束：**轻点停止**
- Live With Me 顶部不显示“第几个瞬间”，只显示拍摄时间。
- 有题目模式顶部显示当前提示；提示旁提供较轻的“换一个”或“跳过”。
