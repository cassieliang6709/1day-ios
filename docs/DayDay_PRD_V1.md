## 1. 产品概述

**名字**：DayDay · 日日是好日
**Logo**：两个并排的 Day 方块——你的一天和朋友的一天拼在一起。方块用手账拼贴质感（纸张、错位、白边），全 App 唯一保留拼贴感的地方。

**一句话定位**：

> DayDay 是一款和亲密朋友互动的视频记录器。随手录制的生活瞬间，既提醒自己记录可爱日常，也能让朋友看见彼此的生活点滴。

**幸福三支柱 → 产品机制**：

| 幸福来源 | 心理学根基 | 产品机制 | 绝不做 |
|---|---|---|---|
| 对生活的感知与记录 | Savoring；感恩记录研究 | 心情印章、按天回看 | 精致内容要求 |
| 无压力的亲密分享 | 低强度高频接触 | Our Days 朋友网 | "谁没记"可见性 |
| 感受到社会支持网络 | 回应方式决定关系质量 | 表情回应、拍一拍、通知中心 | 对话流、计数器 |

**边界（不做清单）**：内容创作工具 / 陌生人社交 / 精致呈现 / Chatbot / 心理治疗 / 深度聊天 / 多巴胺钩子（无 streak、无无限 feed、无红点焦虑）。

**目标人群**：18-28 岁女性为主线（不性别排他）；记录冲动坚持不了的人；2-6 人稳定闺蜜圈。

## 2. 视觉规范：手绘涂鸦风

**一句话**：精确地不精确。每条线都像人手画的，歪就是善意——这里不用做得完美。

### 2.1 色板

| 用途 | 色值 |
|---|---|
| 底色 | `#FFFFFF` 纯白 |
| 手绘线 | `#33332E` 深炭（不用纯黑） |
| 主色 · 鹅黄 | `#F8CE5A`（时间气泡、点亮状态、主按钮） |
| 浅黄底 | `#FDF3D8`（选中态、卡片底、空态） |
| 回应粉 · 皮粉 | `#E5A29E`（仅爱心/表情回应。皮粉带体温感，不甜腻，男女通吃） |
| 波点 | 黑 @ 6-8%，直径 3-4px，只在空白区 |

彩色纪律：**只有鹅黄 + 皮粉两个彩色。皮粉出现 = 有人回应了你，颜色携带语义。**

### 2.2 线条与组件

- 图标：主线 2.5px、细节 1.5px，圆头端点，路径 ±1px 抖动；全套同一只"手"
- **云朵时间气泡**（鹅黄底黑描边抖边）：全 App 视觉签名，承载"这一格的时刻"
- 内容卡片：大圆角 20-24px，照片铺满，素材永远是画面里最亮的
- 按钮：胶囊形，手绘描边
- 时间戳压图：白字 + 深描边
- 底栏：磨砂白胶囊

### 2.3 红线

1. 不设 IP 吉祥物（空态温度靠文案）
2. 不做计数器（爱心不带数字）
3. 不做精美插画（保持笨拙感）
4. 波点不压内容，面积 < 空白区 15%
5. 涂鸦元素只出现在内容的缝隙里

## 3. 文案规范

六原则：陈述事实不评判 / 短句 ≤15 字 / 不惊叹（无感叹号）/ 不催促 / 用"你" / 承认无聊。

永不出现：空话口号、催促、emoji、感叹号、"你真棒"、**连续打卡天数**（连带禁止成就徽章、签到日历、等级体系）。

## 5. 页面详述

### 5.1 首次打开

- 大标题（手写体）：「**日日是好日**」
- 副标题：「一款和亲密朋友互动的视频记录器」
- 无演示动画
- **仅一个入口：通过 Apple 继续**（未来加微信登录；邀请码入口暂不启用）

### 5.2 首次引导（权限 → Avatar 注册）

**Step 1 · 权限**（仅相机 + 通知，不请求其他权限）：
- 相机：「要用相机记东西。拍什么，只有你说了算。」
- 通知：「朋友记了新东西会告诉你。每天最多提醒几次，不会一直响。」

**Step 2 · Avatar 注册**（4 屏内）：

| 屏 | 文案 | 内容 |
|---|---|---|
| ① 给我看看你 | 「用一张照片，画一个你。」<br>「拍一张，或从相册挑。」 | 两个入口：**拍一张**（调相机）｜**从相册挑**（需相册授权）<br>提示行：正面照效果最好<br>次级入口：**先不用头像**（跳过后用名字首字 + 鹅黄底占位） |
| ② 正在画 | 「正在画你。」<br>「几秒钟。」 | 骨架屏，不做转圈。照片上逐渐"长出"彩虹描边与贴纸，约 8-15 秒 |
| ③ 这是你 | 「画好了。这是你。」 | 大图展示，白底 + 彩虹描边，置于浅黄底 `#FDF3D8` 卡片<br>按钮 `就是这样` ｜ 次级 `重画一张`（可无限重画，不设次数提示） |
| ④ 进主界面 | 「好了，去记今天。」 | — |

相册授权话术：「要从相册挑一张照片。只用来画头像，不会上传原图。」

**Avatar 生成规范**（工程/算法）：
- 主体：只保留头部，不含服饰与肩部以下
- 质感：可爱小孩大头贴，幼态化（脸更圆、腮更鼓、线条更软）
- 五官：保留本人特征与发型，可爱化处理，不改成别人；**眼神与角度保持原图不做调整**
- 配饰：只允许三类——两团粉色腮红 + 脸上 2-3 个小贴纸（星星/爱心/波点）。不加眼镜、耳环、帽子
- 描边：外圈一圈手绘彩虹描边（马卡龙色、抖动手绘线条）
- 背景：纯白；输出方形带透明安全边距

**生成 Prompt（可直接给生图模型）**：

> 以照片中人物的头部为基准，生成可爱小孩质感的大头贴头像：大头比例，脸圆润，鼓腮，白底。
> 五官融合：保留照片本人真实的五官特征和发型，做幼态可爱化处理，使其仍然像本人。
> 只保留头部，不要服饰，不要肩膀以下。
> 眼神与角度保持原图，不做调整。
> 配饰：只加两团粉色腮红，脸上散布 2-3 个小贴纸（星星、爱心、彩色波点），总数不超过 3 个，不添加任何其他配饰。
> 整个头像外圈加一圈手绘彩虹描边，马卡龙色，线条微抖动，像蜡笔手绘。
> 背景纯白。

**Avatar 红线**：不做美颜瘦脸大眼（可爱化是画风不是修容，五官结构不许动）；贴纸 ≤ 3 个；描边只一款彩虹；**Avatar 是身份层唯一可加工的地方，时间线素材永远原图，风格永不下沉到内容层**。

**待定**：生成走端侧还是云端（涉及成本与"不上传原图"这句承诺的架构）；重画不留历史版本。

### 5.3 Camera（中页）

**画面与拍摄**：
- **点一下快门，自动拍 2 秒**
- 取景框：**正常圆角 + 黑色边框**（不要涂鸦边框）
- 相机样式**只保留 DV 机**（时间码视觉 + 统一录制比例）
- **时间戳居中**压在画面中央
- **焦段 1–3x 可调**
- 顶部**不显示"今天已拍 N 格"**
- 验收：打开 App 到开始录 ≤ 2 次点按

**画面处理（工程约束）**：
- **不做镜像、不做翻转**：预览与成片方向一致，前置也不镜像
- **双摄时两个画幅都要在框内**：主画面 + 小窗，**小窗不得溢出主画面边界**（拖到边缘时做 clamp，不允许跑出去）

**拍摄区下方四个功能键**（从左到右）：

```
   A 翻转   ｜   B 双摄   ｜   ● 录制   ｜   C 前后置转换   ｜   D 闪光灯
```

- A 翻转 / B 双摄 / 中间录制 / C 前后置转换 / D 闪光灯
- **拍摄按钮下方不写任何文字**（"点一下，拍 2 秒"等说明全部删除，界面靠图标本身说话）
- ⚠️ **A「翻转」的具体语义待确认**：画面 180° 旋转？镜像开关？画幅翻转？A 与 C（前后置转换）的边界要和开发对一次

### 5.4 拍摄完 → 发送

**发送分两条路：一条自动，一条可选。**

1. 拍完自动播放预览
2. **时间戳（居中）下方加一行字幕**——就是写在那一格上的一行手写
3. **① 自动：进 My Days**
   这一段**无条件存入"我的今天"**，不需要点任何东西、不弹确认。拍完就已经记下了。
4. **② 可选：发到 Our Days**
   面板自动弹出，只做一件事：**选择发到哪个 / 哪些朋友网**（一行一个，勾几个都行，**不设上限**）。
   **一个都不勾 = 只留在 My Days。** 关掉面板即可，不作二次确认。
5. 撤销：预览页**左滑 = 丢弃**，零弹窗（自动进 My Days 的那条也一并丢弃）

机制：字幕自己和朋友**都可见**；**逐条即时送达**；对方只看到**点亮状态不剧透内容**；已发送可撤回（那一格消失，不留痕迹）。

- ⚠️ **发送目标以「朋友网」为单位**（进了网 = 网内所有人可见），不是网内逐个成员勾选。若要改成逐个成员，需再确认一次（会让同一段视频在不同成员间产生不一致的可见性）

### 5.5 Our Days（右页，两层）

**第一层 · 朋友网列表**
- 点底栏右页直接进入这里：不同的**朋友网以横向长方形卡片**陈列
- **每张卡片只有三样东西**：

| 位置 | 内容 |
|---|---|
| 左 · 封面 | **成员 Avatar 合集**：按人数排成小网格，**复用第二层的网格规则**（1 人 1×1 / 2 人 1 列 2 行 / 3 人 1 列 3 行 / 4 人 2×2 / 5 人 2 列 3 行末位空 / 6 人 2 列 3 行），最多 6 个；未设头像的成员用**名字首字 + 鹅黄底**占位 |
| 右上 · 群名 | 14px，主文本色 |
| 右下 · 人数 | 12px，三级色小字，如「4 人」 |

- **右上角两个图标**（只放两个，不挤）：
  - **「+」** → 点开二选一：**创建朋友网** / **加入朋友网**
  - **通知中心** → 表情包互动聚合在这里，**看得到是谁回应了你**
- 排序建议：按最近活跃（谁有新内容排前面），不做置顶、不做未读角标

**第二层 · 某个朋友网**（点长方形块进入）
- **人数上限 6 人**，格子铺满整屏
- **网格规则**（竖屏，列 × 行）：

| 人数 | 布局 | 单格比例（宽÷高） |
|---|---|---|
| 1 人 | 1×1 全屏 | 0.56 |
| 2 人 | **1 列 2 行**（上下） | 1.13 |
| 3 人 | **1 列 3 行**（上中下） | 1.69 |
| 4 人 | 2 × 2 | 0.56 |
| 5 人 | **2 列 × 3 行，末位空置**（格子等大，就是 6 人少一格） | 0.84 |
| 6 人 | 2 列 × 3 行 | 0.84 |

- **5 人的空位不渲染任何东西**：无边框、无灰块、无图标、无文案。网格自然缺一角即可。
  ⚠️ 绝不能在这里放"还能再加一个人"的提示——那是把缺席做成了功能入口，违反缺失不可见原则

- ⚠️ **裁切基准（工程必须照做）**：2/3 人和 5 人的末行是**横向格子**（比例 > 1），DV 机的 3:4 竖素材塞进去要裁上下。**一律以画面中心为基准裁**，不许从头顶往下裁——切掉头的格子比窄一点的格子难看十倍
- 竖屏一律走"列少行多"，不走 3 列（3 列会让单格变成窄竖条）
- **裁剪策略**：按 DV 机录制比例截长宽（crop）保证全屏适配；**优先 crop，不留黑边**（letterbox 会让画面看起来像没做完）
- **每个人的视频框可左右滑动**：翻这个人当天的多段片段
- **右上角日历**：切换到别的日期 → **自动播放**；**先放完的视频先定格**（停在最后一帧，不等其他格子），其余继续播
- **缺失不可见**：她今天没记 = 她的格子没有新内容，任何界面不出现"谁没记"字样（全产品最重红线）
- 点头像 → 她的日子页（她在这个网里的片段，按天翻）
- 长按她的格子 → 拍一拍（见 §6.2）

### 5.6 My Days（左页）

**顶部栏**：
- **左上**：个人 Avatar（点头像进设置 / 个人资料）
- **头像右侧**：问候语（**早上好 / 下午好 / 晚上好**，按时段自动切换）+ **今天的日期、时间、周几**
- **右上**：**「新建计划」** 按钮

**新建计划**（点右上角进入）：
- **最下方是录音按钮**（拇指可达位）
- 说完 → 自动转写 → **AI 生成今日待办事项**
- 生成后**可手动编辑**（增、删、改）
- 保存后作为「今天的计划」出现在 My Days
- 💡 建议（可选）：点某条待办 → 直接进 Camera，拍完自动归到这一条下

⚠️ **红线：计划是拍摄提示，不是任务系统**
它是帮你想"今天可以拍点什么"，不是让你完成 KPI。**不显示完成度、不做进度条、不做打卡天数、不催促。** 一旦出现"3/5 已完成"，这个产品就变味了。

**页面其余部分 · 小组件区（并排两张卡片）**：

| 组件 | 内容 |
|---|---|
| **① 心情**（常在） | 标题「**今天的心情怎么样**」+ **5 个手绘表情包**：开心 / 平静 / 累 / 难过 / 生气。**只给自己看，一天一个**（选了就是今天） |
| **② 计划**（有条件出现） | **仅当天有新建计划时出现**，样式参考 iOS 提醒事项小组件：标题「**今天的计划**」+ 待办条目（可勾选） |

- **布局**：两张卡片**等宽等高并排**；**今天没有计划时，心情组件独占整行**
- ⚠️ **红线（勾选 ≠ 完成度）**：打勾是个人记录动作，**允许**。但**绝不显示完成度、不做进度条、未勾选项不变灰、不做连续打卡**。没有"3/5 已完成"这种东西——计划是拍摄提示，不是 KPI
- **我的今天**：今天的录制入口，点进去 = 今日所有片段
- **日历**：翻到过去某天的那页，心情印章一起重现
- **多选生成 vlog**：选中带序号、可拖动排序、生成；导出 9:16 竖版，一键可发微信/小红书
- 不用应用内锁（系统级 Screen Lock 足够）
- 心情数据 iCloud 私有同步（继承 1.5，别人看不到）

## 6. 回应体系（社会支持的心脏）

### 6.1 表情包回应

- 固定 **6 个手绘表情**：**爱心 / 哈哈 / 同感 / 拍手 / 安慰 / 哭泣**（安慰和哭泣覆盖负面情绪场景——朋友难过时也有动作）
- 挂在那一格上；不做对话流；**不显示数字**
- 谁回应了你：**右上角通知中心**（"UU 给了你一个安慰"）
- 皮粉色系，颜色出现 = 有人看见了你
- 红线：不做表情商店。回应是信号，不是创作。6 个，一个都不加

### 6.2 拍一拍

- 入口：长按她的格子 / 她的日子页
- 对方收到弹出提醒，文案（原样使用，不改一字）：

> **「XX 拍了拍你，如果思念有声音，是什么声音呢？」**

- 每天同一个人只能拍一次
- 语义是"我想你了"，不是"你该更新了"

## 7. 验收标准

| # | 场景 | 验收 |
|---|---|---|
| A1 | 打开 App 到开始录 | ≤ 2 次点按 |
| A2 | 拍完到送出（含字幕） | ≤ 3 次点按 |
| A3 | 被邀请者进 App | 第一屏知道"谁叫我" |
| A4 | 表情回应 | 对方通知中心可见是谁、什么表情 |
| A5 | 拍一拍 | 文案原样弹出；同一人每日限一次 |
| A6 | 缺失不可见 | 全产品任何界面不出现"谁没记"类文案 |
| A7 | 心情隐私 | 仅本人可见，iCloud 私有同步可验证 |
| A8 | 注销 | 删除账号后列出删了什么的清单（继承 1.5 S8） |
| A9 | 导出 | 无旋转、无黑帧、无音画不同步（1.5 的口碑坑） |
