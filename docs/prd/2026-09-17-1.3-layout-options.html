已定：拍摄区 C + 瞬间列表 A，另外 B 用于「按时间」那种没有主题的故事。 第一轮选的是 B + A；看到实现之后改成了 C —— 变焦浮层放在烧字上方就不会遮到对成片的承诺，那是 C 唯一的阻碍，位置对了就成立。B 没有被丢掉：它在没有名字的格子上比竖向轨道好，因为「按时间」的故事只有时间可写。

原始建议（留档）：拍摄区 B + 瞬间列表 A。 拍摄区 B 只比 A 多 6pt，但刻度让「能拖」自己说出来，不用教；C 的浮层会压到烧进成片的题目和进度条，那两个是对成片的承诺，遮了就不老实。瞬间列表 A 的竖线在瞬间数量变化时不会散架，B 在七日故事上要横滑七格，C 的左列在非「按时间」故事里没有数据可填。
