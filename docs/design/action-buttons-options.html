按钮组审计 · 3 个通用方案

问题：好几个页面把 2～4 个按钮排成等宽的格子，主按钮和次按钮一样大，看不出先点哪个。

1. 审计结果

根因在组件里。PrimaryActionStyle 和 SoftActionStyle 都写死了 .frame(maxWidth: .infinity)（OneDayControls.swift 第 24、46 行）。只要两个放进同一个 HStack，就自动平分宽度。DESIGN.md 只定了按钮长什么样，没定按钮组怎么排。

4. 选 ① 之后要写进 DESIGN.md 的规则和改动

  1. 一屏最多一个主按钮，它是唯一整行宽的按钮。
  2. 次要操作用 ToolButton：图标 40pt 圆底 + 下面一行字，没有胶囊。一行最多 4 个。
  3. 两个操作时（完成 / 重拍）：次要的放主按钮左边，用 ToolButton。
  4. SoftActionStyle 不再自动撑满：拿掉内置的 maxWidth: .infinity，需要整行宽的调用方自己写。
