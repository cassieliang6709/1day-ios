# 文案梳理：能不写就不写（2026-10-20）

规则只有一条：**按钮、图标、系统弹窗、画面本身已经说明了的，就不写字。** 剩下的字，越短越好，不重复，不催人，不用感叹号。

每条标三种处理：

- **删**：整句去掉
- **缩**：改成右边那句
- **留**：不动

标着「跟第 N 步」的，是那一步删功能时这些字会一起去掉，不用单独改。

一共查了 App 里大约 280 组中文文案。另外有大约 48 组看起来已经没有地方用了，放在最后，删之前我会一条条确认。

## 14. 看起来已经没人用的（约 48 组）

晚间提醒设置页、旧的新建页（自己写 / AI 帮我写 / 提示库 / 模板库）、「先自己拍拍看」「有邀请码？加入朋友」、按住拍 / 松手停、灰框「今天还没拍」等。代码里搜不到用到它们的地方，删之前我会一条条再确认一遍，避免误删。

## 要你定的 3 件事

1. **晚间提醒**：整个关掉，还是改成不催人的说法？
2. **七日计划**：「我的」新建计划还分一日 / 七日吗？还是只有当天的计划？
3. **「怎么用 1Day」那三行说明**：按上面缩短后留着，还是也删掉？
