# CloudKit：登录后找回房间要的索引

`ChallengeStore.restoreMyRooms` 在登录后、每次回到 App 时，按我的用户 ID 查云端，把这台手机上没有的房间补回列表。查询用到两个索引：

| 记录类型 | 字段 | 索引 | 用途 |
| --- | --- | --- | --- |
| `Member` | `userID` | QUERYABLE | 我加入过的房间（成员记录上有 `roomCode`） |
| `Room` | `ownerID` | QUERYABLE | 我建的房间（1.5 (36) 之前建的房间，房主没有成员记录） |

没有这两个索引，查询直接报错；App 只打一行日志，房间列表不变。

## 状态

2026-10-27 已在 CloudKit Console 部署到 Production：
- `Member.userID` QUERYABLE：新建，从 Development 发布，这次发布只包含这一项
- `Room.ownerID` QUERYABLE：之前就有

## 规则

- 房间列表只存在手机本地。云端只能通过「我的成员记录」和「我是房主的房间」知道我在哪些房间。
- 退出房间会删掉我的成员记录，所以退出过的房间不会被找回。
- 1.5 (36) 起，建房间时也会写房主的成员记录。2026-10-28 之后建的房间只按成员记录找回，房主退出过的房间不会因为 `ownerID` 又出现。
- 找回只会加房间，不会删房间。
- 同步时，云端「我自己的 take 1」会认领回本地那一格（`adoptMyTakes`），避免相机把新的一段当成空格拍，再上传覆盖云端原来那段。
