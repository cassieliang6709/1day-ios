「1 段待归档」这个胶囊该放哪

2026-09-20 · RootShellView.draftsBanner

先说它现在是什么

RootShellView 的 ZStack(alignment: .bottom) 最上层压着两个浮动元素：先是 FloatingTabBar，然后是 draftsBanner，后者用 .padding(.bottom, tabBarClearance + 8) 把自己顶到 Tab 栏上方。

if !drafts.isEmpty, surface != .camera {
    Button { showDrafts = true } label: { … }
        .background(
            justKeptADraft ? AnyShapeStyle(OneDay.brandHorizontal)
                           : AnyShapeStyle(Color.oneDayNavy.opacity(0.9)),
            in: Capsule())
        .padding(.bottom, OneDay.tabBarClearance + 8)
}

一个位置，两种状态：刚点过「保留」的四秒里是蓝色渐变带辉光的确认，之后一直是深蓝色的常驻计数。

它丑在哪 — 五条，不是一条

问题为什么
1两个浮层叠罗汉 Tab 栏本身已经是一个悬浮胶囊。在它正上方再放一个胶囊，屏幕底部就变成两个上下挨着的浮动圆角块，谁也不像主角。这是最刺眼的一条。
2深色实心读作报错 oneDayNavy.opacity(0.9)。整个 App 是白卡片加浅蓝底，没有第二个深色实心块。眼睛会把唯一的深色块当成错误提示或者 snackbar，而它其实只是个计数。
3盖住内容，而且滚不开 它是 overlay 不是列表内容。你截图里它正压在第二张故事卡的标题上，而且往下滚多少都甩不掉它。
4一个槽位装了两种东西 「刚保留了 · 查看」是一次性反馈，值得占据底部中央四秒。「1 段待归档」是常驻计数，不值得。现在后者继承了前者的位置和分量，于是一直在喊。
5它不属于任何地方 浮在所有内容之上、不归属任何分组，读起来像系统控件。但待归档的片子是你的东西，它应该长在「我的」里面。

另外它在「计划」和「新建」页也一直在（只有相机页不显示）。你在选模板的时候不需要被提醒有片子没归档。

五个方案

推荐：A + D

把一个槽位拆成两件事。

  1. 保留后的四秒：浮层保持不动。它是对刚发生的动作的回应，占据底部中央是对的，四秒后消失也是对的。
  2. 常驻计数：从浮层变成「我的」列表里的一行，排在「今天」那一组下面。白底、蓝字、虚线边框——和故事卡是一家人，但看得出来不是故事。
  3. Tab 角标：「我的」上一个数字角标。这样你在「计划」或「拍摄」页也知道有东西没归档，但它不会跑到那些页面上来喊。

为什么是这个

  • 常驻信息进列表，一次性反馈留浮层——这是这两种东西各自该待的地方，不是妥协。
  • 待归档的片子是你的东西，「我的」是你的东西的家。放进去它就有了归属，不再像系统控件。
  • 列表行会跟着内容滚，不遮挡任何东西，也不和 Tab 栏叠在一起。
  • 角标是 iOS 的既有语汇，不用解释。它也解决了「换个页面就看不到」这个 A 单独存在时的缺口。

要改哪些

文件改什么
Views/RootShellView.swiftdraftsBanner 的显示条件加上 justKeptADraft——只在那四秒里出现。常驻分支删掉。
Views/Plans/PlansHomeView.swift列表末尾加一行 DraftsEntryRow，点开还是现在那个 ClipDraftsView sheet。
Views/Components/FloatingTabBar.swiftitem 加一个可选 badge: Int?，有值就画角标。
Views/Record/ClipDraftsView.swift不用改。DraftsEntryButton 那个相机内的入口保持原样。

改动集中在视图层，ClipDraftStore 和 sheet 都不动。估计一个半小时，加上模拟器里三种状态（无草稿 / 刚保留 / 有常驻计数）各截一张图确认。

没解决的一个问题

「待归档」这个词本身。它描述的是 App 的内部状态（这个片子还没被归到某个故事里），不是用户的处境。用户的处境是「我拍了个东西，还没想好放哪」。

空状态那句文案其实说对了：「录完找不到地方放的时候，会先存到这里。」但按钮上只剩「1 段待归档」，把那个意思丢了。

可以考虑的替换：1 段还没放好 / 1 段没归到故事里 / 暂存 1 段。这一条单独拎出来，不在这次改动范围里。
