# 1Day story and invitation concept

An isolated, runnable product prototype. Start here: `npm ci`, then `npm run dev -- --host 127.0.0.1 --port 8770`.

- `/`: interactive mobile App concept.
- `/plan.html`: invitation and Free tier rationale, proposed rules, research caveats, and implementation gaps.
- `design-qa.md`: checks and limitations.

Recording, previews, login, uploads, saving, and rewards are explicitly simulated. State resets on refresh. Photos and logo are reused from the existing project landing-page assets. This directory does not replace the native App implementation.

Validation: `npm run build` (includes the mobile runtime integrity check).
