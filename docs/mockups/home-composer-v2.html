二、新建故事：题目看不见怎么解

方案 C · 底部常驻预览条 双卡布局全保留，但底部主按钮上方钉一条「今天会拍这 7 个」——不管你在上面点什么，结果永远在同一个位置实时更新。 选「按时间记录」时它变成「没有题目 · 拍到的每一段按时间排好」，两种模式的结果可以直接对比。 网格卡片的 blurb 也换成前三个真题目，扫一眼就知道内容。代价：底部占掉约 110pt。

我的建议：A 打底，把 C 的两个细节合进去

  • 主体用 A——你要的「主题挑战放左边」直接满足，题目预览条就在双卡正下方，是眼睛落点最自然的位置。
  • 借 C 的一点：推荐网格里那句 blurb（「愿意再过一遍的一天。」）换成前三个真题目（「起床 · 咖啡 · 收拾出门…」）。 blurb 卖的是情绪，题目卖的是内容——在「选之前想知道拍什么」这件事上，后者才有用。两者可以在库页面里再展开。
  • 必须一起修的逻辑：选中「按时间记录」时，下面的推荐网格要禁用并淡出。 现在它还亮着，点一下会静默把 selectedTemplateID 换掉、把你踢出时间模式，而顶部双卡的选中态是从 selectedTemplate?.isTimeOnly != true 反推的（ComposerSteps.swift:69），所以界面会自己跳，用户不知道发生了什么。
  • 顺带一个 bug：selectPromptMode()（ComposerSteps.swift:162）第一行是 if selectedTemplate?.isTimeOnly != true, selectedTemplate != nil { return }—— 已经在七日模式里选了模板时，点「主题挑战」什么都不会发生，卡片没有任何反馈。
