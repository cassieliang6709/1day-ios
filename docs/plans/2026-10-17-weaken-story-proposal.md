# 1.5 淡化「故事」：方案草稿

2026-10-17 · 只是方案，代码还没改。

## 现在「故事」出现在哪

| 位置 | 现在的叫法 |
|---|---|
| 新建页标题 | 今天会是什么故事？ |
| 「我的」首页 | 今天的故事（一行一个，带进度 3/7） |
| 点开片段 | 发到房间或故事 / 打开故事 |
| 成片 | 故事拍完自动出片 |
| 底层模型 | `Challenge`（一个故事 = 一组瞬间 + 一台相机 + 自己 / 朋友） |

问题：用户打开 App 的动作已经是「点中间圆钮拍」，片段先落在「我的」。「故事」变成一个要先理解才能用的容器。

## 核心想法：三个词代替「故事」

| 新词 | 是什么 | 对应现在的 |
|---|---|---|
| **片段** | 拍下的每一段，2 秒 | 不变 |
| **清单** | 今天想拍的几件事，可选 | 「写今天的清单」的故事 |
| **房间** | 和朋友一起拍的地方 | 「和朋友一起拍」的故事 |

「故事」这个词从界面上去掉。一个人拍的、没写清单的日子，不需要任何容器，片段就在「我的」里，每天自动有一支「今天的片」。

## 每个页面怎么改

### 1. 「+ 新建」→ 两个入口

点「+」不再进一整页表单，弹出两个选项：

- **写今天的清单**：直接进清单编辑（自己写 / 帮我写 / 模板），写完选相机就开始。
- **开一个房间**：名字 + 相机 + 邀请朋友。

页面标题改成「今天想拍什么？」（清单）和「开个房间」（房间），不再出现「故事」。

### 2. 「我的」首页

- 「今天的故事」改成 **「今天」**：
  - 有清单：显示清单一行（如「完美的一天 3/7 · 继续拍」）。
  - 没清单：显示「今天的片 · 5 段 · 看一下」，点开就是自动拼好的当天 vlog。
- 房间不在这里出现（在「朋友」tab）。

### 3. 点开片段

- 只有我看得到的片段：主按钮 **「发到房间」**；有正在拍的清单时，菜单里多一项「放进今天的清单」。
- 已经在清单 / 房间里的片段：按钮写清单名或房间名，比如「在 完美的一天 里」，点了跳过去。

### 4. 成片

- 清单拍完 → 「清单的片」。
- 没清单的日子 → 「今天的片」（每天自动生成，可以换音乐、加旁白）。
- 房间 → 「房间的片」。

## 不改的东西

- 底层还是 `Challenge`，只是界面上不叫故事。不动数据结构，旧故事照常打开（显示成清单或房间）。
- 7 日计划已经在这一版去掉了。旧的 7 日故事还能打开、继续拍。

## 要你定的

1. **「今天的片」要不要每天自动生成**，还是用户点了才生成（自动生成要后台导出视频，费电）。
2. **清单要不要保留「一天」的边界**：今天没拍完，明天还显示吗？
3. **「+」弹两个选项**，还是清单放在「我的」页里、房间放在「朋友」页里，各自有入口、去掉「+」？
4. 「故事」这个词是**完全去掉**，还是只在成片标题里保留（比如「10 月 17 日的故事」）？

## 工作量估计

| 部分 | 估时 |
|---|---|
| 文案替换（新建、我的、点开片段、成片） | 半天 |
| 「+」改成两个入口 | 半天 |
| 「我的」里的「今天的片」 | 1 天 |
| 点开片段的按钮按清单 / 房间区分 | 半天 |
| 合计 | 约 2.5 天 |
