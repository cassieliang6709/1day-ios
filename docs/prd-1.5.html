1. 产品概述

一句话：点一下拍一段 2 秒的视频，1Day 自动按时间拼成一支片；可以一个人拍，也可以和朋友在同一个房间里拍同一天。

1.5 改版方向

  • 底栏三格：左「我的」、中间实心圆拍摄、右「朋友」。拍摄从一个藏在故事里的动作变成主入口。
  • 我的 = 个人素材库 + 日记：最上面记今天的心情；所有片段（自己拍的、房间里的、不属于任何故事的）都落在这里，可按相机和待归档筛选、按日历看过去的日子、多选生成 vlog。
  • 朋友 = Setlog 式房间：房间里每人一格，自动播放每个人今天最新的一段；没拍的人是灰框，可以拍一拍提醒。
  • 相机决定画面：一个故事或房间只用一台相机（DV 机 / 胶片机 / 拍立得），所有人拍出来风格一样。
  • 选题弱化：模板、写清单、AI 帮写还在，但收进「新建」那一页里，不再是打开 App 的第一步。

4.3b 待归档改版：拍完即决定 + 选好友圈 规划中

替换现在的「这段还没归档 · 保留 / 丢弃」弹窗和 4.3 的待归档筛选

拍的那一下：和发语音一样，拍的时候手指往上划 = 撤销，这段不留。不再在关闭时弹「这段还没归档」。

拍完以后进待归档页：

  • 第一格叫「我的」，右上角「⋯」。所有片段默认先放在「我的」里，只有自己看得到。
  • 下面是好友圈 1 / 好友圈 2 / 好友圈 3…，每个圈是一组朋友（对应现在的房间）。
  • 选一个片段，勾上要发到哪几个好友圈；可以一个都不勾，就只留在「我的」。
  • 每个片段上能看到它已经上传到了哪些好友圈。
  • 「⋯」里：删除、改字幕、管理好友圈。

验收拍一段到决定要不要，0 次额外点按；发到好友圈 ≤ 2 次点按；任何片段都能一眼看出发到了哪些圈。

待定拍摄已改成「点一下拍 2 秒」，手指不在屏幕上，原来设想的「按住时上划撤销」用不了，撤销要换一种做法；好友圈和现在的房间是不是同一个东西；已经发出去的能不能撤回；这和 2026-10-14 决定暂时不做的「拍完直接发到房间」要合并重新决定。

4.4 今天的心情（心情日记第一版） 已做 涂鸦没做

我的页最上面 · MoodStore · MascotChatService · 截图同 4.1

「我的」不只是素材库，也是我自己的日记本。视频记下今天发生了什么，这一块记下今天我是什么心情。

  • 5 种心情：开心 / 平静 / 累 / 难过 / 生气，每种是一个小方块表情。点一下脸就记下。
  • 一句话：可以写一句（最多 120 字），也可以点麦克风说话，自动转成文字。
  • 记下以后：卡片收起，显示大表情、那句话和「今天记下了」；点「改」或点表情可以重新编辑。卡片底部写着「只有你自己看得到」。
  • 和小方块聊两句：小方块先回一句，可以接着聊，每天最多 10 条。聊天记录只存在手机上，不上传。没网时小方块回一句固定的话。
  • 日历联动：「我的」月历和所有片段的日期旁边显示当天的表情；朋友房间的日历不显示（心情只给自己看）。
  • 同步：心情存在手机上，并同步到用户自己的 iCloud（私有，别人看不到），换手机不丢。
  • 涂鸦：没做。原计划手指在当天格子上画画（PencilKit），第一版只有选心情 + 一句话，估时约 2 天。

验收打开「我的」到记下今天的心情 ≤ 2 次点按（实际 1 次：点脸）；不拍视频的日子也能留下一格。

待定涂鸦是每天一张还是可以多张；生成 vlog 时要不要把涂鸦当片头或贴纸。这一块也部分回答了「第二天为什么再打开」（见第 10 节）。

5. 拍摄

5.1 自由拍摄（底栏中间）

RecordClipView · 10-16 新截图（模拟相机，取景框是胶片机）
  • 点一下快门，自动拍 2 秒。快门下面写「点一下，拍 2 秒」。原来的「按住拍、松手停」和「最长 2 秒」提示都去掉了，用户不再选每段长度。
  • 取景框按当前相机显示比例、边框和日期（截图是胶片机：2:3、右下角橙色日期）。
  • 右下两个按钮：切换前后摄像头、换相机。只有自由拍摄能换相机，并记住上一次选的；从故事或房间进来时用那个故事的相机，「换相机」按钮隐藏。
  • 去掉了竖 / 横 / 方切换按钮，所有新拍摄都是竖拿。
  • 默认后置摄像头。前置只有 1x/2x，1x 就是整颗传感器，不加 0.5x。
  • 右上角是待归档片段数量（截图里是 4），点一下跳到「我的」的待归档筛选。
  • 双摄按钮（两个叠在一起的取景框图标，开启时小框填品牌色）只在支持的真机上显示，模拟器没有，所以截图里看不到。

验收 S3从点中间圆钮到开始录 ≤ 2 次点按（现在是 2 次：点圆钮、点快门）。

  • 1.5 之前建的故事没有相机，用户在相机页自己选；之前存成横屏或方形的故事保持原来的形状。

5.3 双摄小窗（前后摄同时录）

模拟器没有双摄，无截图
  • 后置全屏，前置是一个小窗，样式是白边相纸（圆角、白边、轻阴影）。
  • 小窗可以拖到任意位置，双指缩放（宽度占画面 22%–45%）；点一下小窗互换前后摄。
  • 拖动时不再抖动（之前拖动会剧烈抖动，已修好）。

5.4 拍完预览

6. 故事

6.1 新建：今天会是什么故事？（一页做完）

StoryComposerView · ComposerSteps · 10-16 新截图，左：上半页 · 右：往下滑

原来要先选入口、再展开「更多模板」选一日 / 七日、最后弹出第二页「设置」。现在所有选择都在一页里，从上到下：

  • 名字：带封面小图，可以改。
  • 自己拍 / 和朋友一起拍：自己拍下面写「只在这台设备上」。
  • 用哪台相机拍：三张卡片，小方块风格的相机图标。卡片说明已改为「3:4 · 原色 · 时间码 / 2:3 · 微暖 · 橙色日期 / 3:4 · 原色 · 白边相纸」（截图拍于改字之前，还是旧文字「冷色 / 暖色 / 淡色」）。默认胶片机。

「自己写」和「AI 帮我写」合成一个「写今天的清单」页：上面一句「今天想做什么？」加小按钮「帮我写」让 AI 填清单，下面是可以改的清单。

8. 朋友与房间

8.1 朋友 tab

RootShellView · 10-16 新截图（模拟器没登录，所以是空状态）
  • 0 个房间：空状态「还没有和朋友一起拍的故事」，说明大家拍的会剪进同一支片；主按钮「邀请朋友一起拍」，次入口「我有邀请码」，右上「加入」。

  • 多个房间：显示房间列表。
  • 「邀请朋友一起拍」按房间数走：0 个房间 → 打开新建页并默认选好「和朋友一起拍」；1 个 → 直接进房间并弹出邀请码；多个 → 先选房间。
  • Debug 版设置里有「创建测试房间」：建一个带两个假朋友片段的真房间（只在开发环境），显示邀请码，方便测试。

8.2 房间（一人一格）与聊天

RoomFeed · RoomChatView · 房间页这次没有新截图（模拟器没登录）；左图是旧的聊天截图（10-15）
  • 一人一格：两列网格，每个成员一格。今天拍过的人排前面，格子里静音循环播放他最新的一段，显示头像、名字、大号时间和字幕；点格子全屏、有声音。
  • 爱心和回复：朋友的格子右侧有回复和爱心。爱心点了变红，再点取消；回复打开房间聊天。自己的格子没有这两个按钮。
  • 灰框：今天没拍的人是灰色格子，写「今天还没拍」/「N 天没拍了」（2 天及以上）/「还没拍过」。自己的灰框点一下去拍。
  • 拍一拍：朋友的灰框底部有「拍一拍」，点完变「已拍」，同一个人每天只能拍一次。对方收到通知「<名字> 拍了拍你，快来拍一段」；静音的房间不弹通知。
  • 房间日历：右上角切到日历，按日期看房间里所有人的片段。不显示任何人的心情。
  • 聊天：消息可以引用某个瞬间（「晨光 ↗」）；弱网发出的消息恢复网络后自动补发。
